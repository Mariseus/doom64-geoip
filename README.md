# doom64-geoip
Geoip for xray core routing
--
##Description

This repository does not contain a complete list of Russian domains. It is intended for routing by the XRAY Core client for the Doom64 VPN.

Domains will be added over time, and the resource will be migrated to SELFHOSTED in the future.

Special thanks to the following repositories and their creators:

https://github.com/v2ray/domain-list-community - https://github.com/v2ray

https://github.com/hxehex/russia-mobile-internet-whitelist/blob/main/whitelist.txt - https://github.com/hxehex
